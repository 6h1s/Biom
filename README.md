# Biom

A personal health and training dashboard for iPhone and Apple Watch, styled after Apple Fitness.

- Everything is stored **on the device** (browser storage). This repository contains only the app, never any health data.
- Data comes in from Apple Health and the Watch through iOS Shortcuts ("Sync" and "Log set"), or by importing a file.
